TC1: State Transition with Edge Cases

Apply reset:
reset_tb <= '1'; wait for 2 cycles; reset_tb <= '0'; wait for 2 cycles;

IDLE → DISPLAY (BTNC pressed):
BTNC_tb <= '1'; wait 1 cycle; BTNC_tb <= '0'; wait 5 cycles;

DISPLAY (invalid SW = "000", no transition):
SW_tb <= "000"; BTNC_tb <= '1'; wait 1 cycle; BTNC_tb <= '0'; wait 5 cycles;

DISPLAY → INSERT (valid SW = "001"):
SW_tb <= "001"; BTNC_tb <= '1'; wait 1 cycle; BTNC_tb <= '0'; wait 5 cycles;

INSERT (not enough money, inserted = 50, no transition):
inserted_amount_tb <= 50; BTNC_tb <= '1'; wait 1 cycle; BTNC_tb <= '0'; wait 5 cycles;

INSERT → DISPENSE (inserted = 130 meets selected_price = 130):
inserted_amount_tb <= 130; BTNC_tb <= '1'; wait 1 cycle; BTNC_tb <= '0'; wait 5 cycles;

DISPENSE (switch still ON, no transition):
SW_tb <= "001"; BTNC_tb <= '1'; wait 1 cycle; BTNC_tb <= '0'; wait 5 cycles;

DISPENSE → IDLE (switch OFF):
SW_tb <= "000"; BTNC_tb <= '1'; wait 1 cycle; BTNC_tb <= '0'; wait 5 cycles;
